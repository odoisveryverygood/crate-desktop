# CRATE Windows desktop port

Windows x64 installer and portable application, using the CRATE layout, original Studio sounds and hosted Jev/GPT backend. Run CRATE-Setup-0.4.0-x64.exe to install, or extract the full ZIP and open CRATE.exe with its resources beside it. Enable AI help to connect automatically. No provider keys are bundled or requested.

This is a separate Electron/Web Audio port of the sampler. The native Swift Mac app remains separate. It includes 16-pad banks, sample preview/load/chop, multi-part layering, groove templates, step editing, playable keys, pad trim/reverse, filter/volume/half-speed/mutes, audio import, microphone-recording controls, project save/load, Undo/Redo and WAV export. AI preserves an instant local beat and refines patterns in the background; tokens are enrolled per installation and encrypted with OS storage when available. The app never stores provider keys.

Keyboard: Z/X/C/V, A/S/D/F, Q/W/E/R, 1/2/3/4 play pads; Space toggles playback; Ctrl-L opens the library, Ctrl-O imports, Ctrl-S saves, Ctrl-Z undoes. KEYS uses the marked musical typing layout. Performance input yields to text fields and releases held notes on focus loss.

Dependencies: Node 24, `npm ci`. Prepare the original library with `node scripts/prepare-assets.mjs /absolute/path/to/StudioLibrary` or generate it using `tools/generate_sampler_library.py`. Run `npm test`, then `npm run verify` for actual renderer/audio/project checks in isolated storage. Standard verification uses no AI calls or real user projects. `npm run verify:hosted` explicitly adds two live hosted provider calls in isolated storage; trusted branch-push CI runs that check on Windows. `npm run build:windows` produces the x64 installer and ZIP on Windows with CRATE executable metadata. `npm run build:windows:cross` produces a local unsigned ZIP on macOS without executable resource editing; the Windows-runner artifact is preferred for distribution. Native Windows packaging and installed-app verification were previously exercised on a Windows runner in the development checkout. This public snapshot does not publish or deploy packages automatically.

Release limits: unsigned Windows beta; not an Authenticode-signed public installer. The Windows executable cannot be run directly on the development Mac; distinguish the common engine checks on macOS from native Windows runner results. Microphone capture, device-driver compatibility and latency need physical Windows testing. Advanced native Mac functionality such as its song-arrangement editor, per-bar performer, audience window, speech transcription and complete FX stack have not been ported. Windows projects currently use their own format and storage rather than automatic Swift project conversion. This port should be labeled a beta, not full feature parity.

The same bounded hosted beta quotas apply. The gateway uses anonymous installation sessions; account/billing plans would need user authentication. Do not promise unlimited free AI.
